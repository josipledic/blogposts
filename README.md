# blogposts

## format

The blogposts are written in .mdx format and contain meta/frontmatter info in their header.

## deployment

You have to retrigger the same build on Vercel for the gitgud website to pick up the latest blogpost files from here.

## localized posts

English posts live in the repository root. German mirrors use the same filename under `de/`, allowing the publishing application to expose them below its `/de/` route while keeping the locale explicit in the content source.
